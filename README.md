# my-cat
this repository contains the linux cat command I personally coded using C.

first you'll have to compile the c file itself (the code) by entering " gcc my-cat -o my-cat-program " into the command line using a c compiler (i used gcc in my example)

after doing the first step, it simply works by entering the c file's directory as the first input and the directory of the file you want to see on the screen as the second input.

heres an example input:

./my-cat-program ./hw.txt

(since they're in the same directory in my example)

and you'll see the hw.txt file content on your screen.
